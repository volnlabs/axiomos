# Repository Refactor Plan

This plan tracks the repository-structure and tooling migration on the
`audit/runtime-architecture-hardening` branch. It is the execution ledger for
this refactor; it does not replace architecture, reference, or ADR documents.

## Invariants

- `cargo xtask` remains the only canonical repository command.
- Existing build, run, deploy, debug, and audit commands keep working during
  migration; compatibility wrappers are retained when paths change.
- Generated files are regenerated by their existing generator before and after
  each move.
- No workspace member, artifact path, or CI entry is removed without an
  equivalent replacement and a passing manifest check.
- Historical audit evidence is preserved verbatim unless a separate corrective
  documentation change is explicitly identified.
- Each structural move is a separate commit with a gate result recorded here.

## Execution checklist

- [ ] Inventory authoritative, generated, operational, proposed, and historical
      files.
- [ ] Add `docs/README.md` and `scripts/README.md` authority guidance.
- [ ] Add metadata to substantial active docs and ADRs.
- [ ] Move generated documentation under `docs/reference/generated/` and update
      xtask paths.
- [ ] Group scripts by responsibility with compatibility wrappers.
- [ ] Split xtask into CLI, command, manifest, validation, documentation, and
      process modules without changing behavior.
- [ ] Replace handwritten TOML parsing with `serde` and `toml`.
- [ ] Add typed xtask exit categories and structured command output.
- [ ] Add declarative quick/full/extended CI profiles while retaining `xtask ci`.
- [ ] Add shared repository-model loading for manifests and workspace data.
- [ ] Decompose the audit shell script only after equivalent xtask checks pass.
- [ ] Add kernel crate-boundary and component-naming documentation.
- [ ] Relocate generated root artifacts and consolidate TODO tracking.
- [ ] Reassess root `src/main.rs` and `build.rs` ownership before creating an
      image-builder crate.

## Explicitly deferred

- Optional TUI; it follows a stable CLI and must display the equivalent command.
- Broad userspace and firmware directory moves until workspace and component
  manifests can validate them automatically.
- Moving `ENGINEERING_AUDIT.md` until all links, generated references, and
  release evidence paths are migrated.
- Deleting old paths; compatibility wrappers remain until one full gate confirms
  all callers have migrated.

## Per-commit verification

Each commit must pass, as applicable:

```text
cargo fmt --all -- --check
cargo xtask inventory --check
cargo xtask boundary --check
cargo xtask docs --check
scripts/verify-engineering-audit.sh --quick
git diff --check
```

The full gate is required before merging the completed refactor. Any failed
step, stale generated file, broken compatibility path, or workspace drift
stops the migration until resolved or explicitly recorded above.
