# v0.5.0-alpha.1 release plan

## Objective

Publish an annotated `v0.5.0-alpha.1` repository tag from `dev` without
merging `dev` into `main`. This is an alpha for the completed v0.3/v0.4
software foundation and initial hardware-safety RTL; it is not a claim that the
v0.5 runtime-evolution feature set or physical robot assurance is complete.

## Completed work

| Area | Status | Evidence |
|---|---|---|
| v0.3 code | Complete | Pi5 GPIO IRQ creates `GpioEvent` and executes immutable BPF GPIO routes; PWM is mediated by the actuation monitor; kernel-owned e-stop, audit events, and the authority lattice are wired. |
| v0.4 code | Complete at repository-source level | Pi5↔Shrike control link, RP2040 firmware, IIO event dispatch, verified `forward_drive`, `obstacle_stop`, and `wall_follow` behaviors, and the portable final-PWM safety RTL are present. Board-specific FPGA integration remains physical-release work. |
| Final PWM safety RTL | Complete as portable RTL | `fdd5bf0` adds `firmware/shrike/fpga/shrike_safety_gate.sv` and its self-checking testbench. A low physical e-stop or either command outside ±800 per-mille gates both motor PWM outputs low combinationally. |
| Local/hosted verification plumbing | Complete | `92e7bd3` adds the Icarus-Verilog runner to the full local audit gate and a dedicated GitHub Actions job. |
| Documentation | Complete for alpha scope | Release policy and architecture explicitly distinguish RTL simulation from a board project, bitstream, and HIL. |

fuzz builds, and the required cloud-profile Miri suite. Its retained local
manifest is `artifacts/runs/1784387660-check-all/manifest.txt`; it records

were committed immediately afterward as `92e7bd3`. The source and commands
executed by the FPGA gate are unchanged between those commits.

The two skips are intentional and recorded by the gate:

1. Audit fault-injection QEMU smoke was not selected (`RUN_AUDIT_FAULT` unset).
2. SMP-4 scheduler smoke remains deferred pending cross-CPU wakeup/IPI
   ownership work.

## Remaining actions

1. Run the documentation, inventory, and FPGA checks after this plan/review
   update.
2. Create and push an annotated `v0.5.0-alpha.1` tag from the resulting clean
   `dev` tip; do not merge to `main`.
3. Publish prerelease notes using the scope and non-claims below, and retain the
   local-gate manifest with the release record.

## Explicit non-claims

- No hosted Actions evidence exists until billing/quota is restored, even though
  the FPGA job is configured.
- No ForgeFPGA board project, pin constraints, synthesized bitstream, or
  physical timing/HIL evidence exists yet.
- Physical Pi5/RP2040 GPIO, control-link, e-stop, and 24-hour soak validation
  remain outstanding.
- The v0.5 behavior registry, epoch-quiesced hot-swap, rollback, and durable
  flight recorder are not implemented; this alpha establishes their hardened
  substrate, not the runtime-evolution release itself.
