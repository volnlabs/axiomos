# Same-manager publication evidence, v2

This immutable capture contains 28 correctness records and 244,364 hosted cost records from 80 fresh processes (80,000 raw replacement attempts). It compares the same manager checks and resource-atomic commit with atomic publication (AP) or a guarded invocation gate (GR). Attach-first and detach-first remain supporting failure witnesses.

`environment.json` identifies the base commit, source patch and untracked sources, canonical source digests before/after capture, measured executable hashes, commands, CPU affinity/topology, scheduling environment, and exit status. `build-command.json` and `build-artifacts.jsonl` connect compilation to the captured executable paths. All source and executable hashes remained unchanged during capture. The later paper layout edit does not change the captured code or results.

`trace.jsonl` and `cost-trace.jsonl` are raw records; `test-output.log` retains original test output. CSV and LaTeX files are generated by the two analyzers. The ordinary test and warmup output remain in the raw log; warmup is excluded from timed samples. Per-process counts, medians, nearest-rank p99s and maxima are in `cost-analysis.json`. Reported latency cells aggregate process medians/p99s. First-try denominators are logical requests started; skip denominators are successful activations. A final unfinished logical request can make these denominators differ. Scheduler misses and all runs are retained.

The caller imposes invocation holds; hosted observations retain real snapshot guards but do not execute privileged BPF bytecode. Memory counts are manager-accounted resident bytecode bytes, not RSS. No physical execution, real-time guarantee, downstream queue fencing, or task-learning quality is established here.

Reproduce from the repository root with `CARGO_TARGET_DIR` set to a writable build directory:

```sh
python3 scripts/benchmark/reproduce-update-publication.py --output /path/to/new-evidence --dispatch-cpu 12 --update-cpu 14
```

Choose two distinct physical cores on another host. Existing output directories are rejected. Generated PDF and these identifying provenance artifacts must not be submitted together for anonymous review.

`validation/` retains separate unit, Loom, cross-compilation and QEMU checks. The QEMU process was intentionally stopped by a 55-second timeout (exit 124) after the replacement/interpreter and later BPF smoke markers passed; it is an idle boot, not a terminating test. These checks are separate from the 80-run hosted experiment. No source change was required after the final checks.
