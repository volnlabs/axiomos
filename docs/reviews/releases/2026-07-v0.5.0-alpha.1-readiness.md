# v0.5.0-alpha.1 release readiness review

## Decision

**Ready to tag as an alpha after this documentation update is committed.** Do
not merge `dev` into `main` as part of this release.

This decision is deliberately narrow: it approves a prerelease tag for the
v0.3/v0.4 software foundation and the initial Shrike-lite FPGA safety-gate RTL.
It does not approve a safety-relevant deployment, a physical-robot release, or
the roadmap's full v0.5 Runtime Evolution feature claim.

## Residual risk and follow-up

- ForgeFPGA constraints, a board-specific project, synthesized bitstream, and
  physical timing/HIL validation remain absent.
- Physical Pi5/RP2040 GPIO, control-link, e-stop, and soak evidence remain
  release gates for a hardware claim.
- The engineering audit remains 7/10 and NO-GO for v1.0 or safety-relevant
  deployment; hosted H-06 and independent safety/concurrency review are still
  open.
- v0.5's behavior registry, hot-swap, rollback, and durable flight recorder
  remain future implementation work.
